# Termy for Homebrew

```sh
brew tap ycankasal/termy
brew trust --tap ycankasal/termy   # Homebrew 7+ only loads casks from trusted taps
brew install --cask termy
```

[Termy](https://www.apptermy.com) is a notch terminal for Claude Code and Codex: approve tool calls, answer questions and follow every agent from the MacBook notch or the menu bar. It updates itself through Sparkle.
